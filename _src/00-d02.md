# D02 · Arrays and simulation

Start with the array's layout, then decide what a scan needs to remember and whether it may overwrite the input. Review [D01](00-d01.md) for invariants and cost accounting, and use [Array tricks](05-array_tricks.md) and [Matrix](20-matrix.md) for Dojo templates.

## Guided walkthrough

1. **D02.01 · Array memory.** In a packed fixed-width array, element i begins at base + i × width. A CPython list stores references in its backing array, and the objects can live elsewhere. Inserting at the front requires shifting the existing references.
2. **D02.02 · Dynamic growth.** A resize can allocate a larger buffer and copy every existing entry. In a doubling model, the sizes copied through capacity 8 are 1, 2, and 4, for seven copies total. This gives constant amortized append cost in the model and allows individual appends to be linear.
3. **D02.03 · In-place scans.** Keep the reader’s position separate from the writer’s position. For Move Zeroes, after reading a prefix, positions before the writer contain exactly that prefix’s nonzeros in their original order. This invariant explains why reading and writing the same array works.
4. **D02.04 · 2D indexing.** In a flat row-major 2×3 grid, zero-based coordinate (1,2) maps to 1 × 3 + 2 = 5. Validate both axes before flattening. A nested list can be ragged, so a single stride only works once the rectangular layout is established.
5. **D02.05 · Rotations.** A right rotation by k moves index i to (i+k) mod n. For [1,2,3,4] rotated by 5, reduce the shift to 1 and obtain [4,1,2,3]. Handle n=0 before computing a remainder.
6. **D02.06 · Monotonicity.** The running minimum price can only stay the same or fall. At each potential sell day, retaining the cheapest preceding price is enough to score the best legal gain. The global maximum and minimum alone lose the order of the days.
7. **D02.07 · Frequency.** When keys range from 0 to 2, a three-entry count array records [2,0,2,1] as [1,1,2]. Weigh the size of the value domain against the number of distinct observed keys before choosing a count array or dictionary.
8. **D02.08 · Edge cases.** For each problem, specify the empty and singleton results, whether duplicates are distinct, and whether input mutation is allowed. Maximum subarray over a nonempty input must return −2 for [−5,−2,−8]. Starting the answer at zero silently permits an empty segment.

### Worked case

On prices [7,1,5,3,6,4], the running minima are [7,1,1,1,1,1] and the best gains so far are [0,0,4,4,5,5]. The full baseline scores 15 buy/sell pairs. The optimized scan visits six prices and keeps two scalar values. On [7,6,4,1], subtracting the global minimum from the maximum gives 6, but the maximum occurs before the minimum, so the legal profit is 0.
