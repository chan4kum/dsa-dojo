# D01 · Complexity, math, and recursion

Use this note alongside [Foundations](00-foundations.md) and [Bits and math](16-bits_math.md). D01 is the mastery roadmap’s group ID. The Dojo trainer uses a separate topic and problem number.

## Guided walkthrough

1. **D01.01 · Bits and integer representations.** An unsigned 8-bit word has values 0–255. In two’s complement, the top bit contributes −128, so the same bit pattern `11111111` represents −1. Python integers grow as needed, so explicitly specify width and overflow behavior when modeling a fixed-width boundary.
2. **D01.02 · Asymptotics.** Define the input size and what counts as one operation. A pass over `n` entries is Θ(n) if each iteration does fixed work. An outer pass that copies a length-`n` slice per entry performs Θ(n²) copying work. Count peak auxiliary memory and output storage separately.
3. **D01.03 · Limits and series.** Reversing `1+2+…+n` and adding the two sums gives `n` copies of `n+1`, so the sum is `n(n+1)/2`. For sizes `n, n/2, n/4, …`, the geometric sum is less than `2n`. These represent different ways the inner work can vary across iterations.
4. **D01.04 · Recurrences and Master Theorem.** In `T(n)=2T(n/2)+n`, every level costs `n` and there are Θ(log n) levels, for Θ(n log n). The Master Theorem applies to eligible equal-size divide-and-conquer recurrences. For `T(n)=T(n−1)+n`, expand the recurrence and use the arithmetic sum instead.
5. **D01.05 · Induction and invariants.** State what is true before and after each iteration. In trial division, before candidate `d`, no integer in `[2,d)` divides `n`. The base case has an empty range. A failed divisibility check extends the range by one. Exhausting the inclusive cutoff proves primality because a composite integer has a factor at most `⌊√n⌋`.
6. **D01.06 · Recursion stacks.** Each active call holds its pending work. A recurrence with two half-size calls can visit Θ(n) nodes while using Θ(log n) live frames if it executes one child at a time and stores bounded state per frame. A chain that decreases by one has Θ(n) live frames. Include referenced inputs and temporaries when estimating peak memory.
7. **D01.07 · Amortization.** In a doubling-array model starting at capacity 1, growing to fit nine entries copies `1+2+4+8=15` old entries in total. Individual resize steps may be expensive, but the total copy count across `n` appends is Θ(n) in this model, so each append has constant amortized cost.
8. **D01.08 · Constraints.** Derive a concrete operation and memory budget. Enumerating all unordered pairs from 100,000 items visits `100,000×99,999/2 = 4,999,950,000` pairs. If the required output lists every pair, the output itself imposes that scale. If the output is a match or a count, a different representation may avoid enumerating them.

### Worked case

For `49`, test candidates `2` through `7`. The upper endpoint `7` divides `49`, so the result is composite. A loop that excludes `⌊√n⌋` returns the wrong answer. For `97`, the baseline tries 95 divisors from 2 through 96, while the square-root-bounded version tries 8 from 2 through 9. Those counts measure divisor checks. Bit complexity also depends on the cost of integer arithmetic as the input grows.

## Applied assessment

Award one point per result supported by its reasoning. Four of five meet the 80% threshold. Change the inputs for delayed recall and attempt the cases before opening the feedback.

1. Interpret `10010000` in signed eight-bit two’s complement.
2. Count comparisons when item `i` compares with every earlier item for `n = 16`. Give the tight bound as `n` grows.
3. For powers of two, solve `T(n) = T(n/2) + n` with a constant base case. Give the geometric sum that bounds it.
4. A developer replaces the inclusive square-root cutoff with an exclusive cutoff. Give a failing input other than `49` and trace its missed divisor.
5. A dense float32 score matrix must fit a 16 MiB buffer by itself. Find the maximum square dimension and state which allocation assumptions the calculation makes.

<details>
<summary>Answers and rationale</summary>

1. `−112`. The top-bit weight is `−128`, and the other set bit contributes `16`.
2. `120` comparisons, since `0+1+…+15 = 16×15/2`. The bound is Θ(n²).
3. Θ(n). The per-level work is `n+n/2+n/4+…`, which is below `2n` before the constant base case, and the first level alone costs `n`.
4. For `25`, candidates `2`, `3`, and `4` all fail. Divisor `5` is the cutoff and must be checked.
5. `2,048`. Four bytes per entry and `16×2²⁰` bytes allow `4,194,304 = 2,048²` entries. The model includes only one densely stored score matrix.
